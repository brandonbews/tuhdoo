# tuhdoo data branch

This branch is the coordination ledger for this repository. It is kept by
**tuhdoo**, a shared backlog, work queue, and activity ledger for a fleet of
agents steered by humans, synced over the repository's existing git remote.
The branch holds the append-only event log under `events/` and these
generated markdown views. The views are derived from the log; never edit
them by hand. Docs: https://tuhdoo.com
