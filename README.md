# tuhdoo data branch

This branch is the coordination ledger for this repository, kept by
**tuhdoo** — a shared backlog, work queue, and activity ledger for a fleet of
agents steered by humans, synced through this ordinary git branch. It holds the
append-only event log under `events/` plus these generated markdown views. The
views are derived from the log — never edit them by hand. The design lives in
`docs/` on the repository's main branch.
